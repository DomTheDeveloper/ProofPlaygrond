# Verification

Lean 4.35.0 compiled `PoleDescent.lean`, `FreePoles.lean`, `PowerFreeCounting.lean` and `PowerFreeGlobal.lean`. The two new analytic modules produced no diagnostics in the ordinary command-line compiler. The compiler record is in `verification/native-builds.txt`. `verification/pole-audit.txt` is the output of a separate native Lean invocation that imported the compiled proofs.

The audit queried 24 declarations, covering the whole-plane theorem, orders, residues, arithmetic series and integral. Their reported axioms are `propext`, `Classical.choice` and `Quot.sound`. Each of the ten applications to RH passed its target check. The finite sieve and its examples had a separate compiler run. The two numerical statements for the counts through 1,000 report zero axioms.

## Upstream theorem

The compact source declares `riemannHypothesis : RiemannHypothesis` with proof term `New.zeta_zeros_on_line New.grh`. The bundled `verification/upstream/Main.olean` is from the published Lean community CI cache for the readable edition at commit `1053c8dddfb0a168e8a60ac437d06f665fd012df`. The CI source tree is `55fe9c6cb2e5be421c5871e772b6d736ecb5d164`, identical to the readable source tree in the independently checked release. Its named theorem, type and literal proof term also match the pinned compact source. The binary SHA-256 is `0fa731cf77514371b6bed2b575e126fd95bb3e2229e10bfbc77756e7460ccf89`. The archive records its cache provenance, original license and notice alongside it. [CI source endpoint](https://github.com/leanprover-community/riemann-hypothesis/blob/1053c8dddfb0a168e8a60ac437d06f665fd012df/grh/src/Main.lean) · [Compact source endpoint](https://github.com/lsernau/grh-lean/blob/72fead102f663d5c7a407964a13dc0cf9d977207/grh-compact/src/Main.lean)

`PoleAudit.lean` reads the actual upstream theorem declaration and requires its type and proof body to match those endpoints. For each downstream theorem, Lean's kernel checks the application abstracted over that exact RH premise. The checker substitutes the upstream theorem into the resulting conclusion and requires kernel definitional equality with a separately stated target. It leaves the imported environment untouched. The upstream proof and its dependencies were independently checked in both editions. [Andrew Sutherland's verification record](https://math.mit.edu/~drew/shortgrh/)

The direct facades in `PowerFreePoles.lean` and `PowerFreeResidues.lean` apply the existing RH theorem in a single line per result. The ordinary combined build of those facades remains a separate replay. Locally, the older upstream `Main` required thousands of missing Mathlib private dependency files. Automatic resource review stopped their bulk restoration because of disk and memory pressure. The local result uses the compositional audit above. `check.sh` includes both build modes.
