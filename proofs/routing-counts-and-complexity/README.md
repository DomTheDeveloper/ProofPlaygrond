# Restricted routing, counting and computation

The five editable manuscripts and accompanying replication programs study three-lane switching counts, single-tour decision and counting, Hamiltonian-cycle parity in cubic graphs, four edge-color clues and two blue edge-color clues. Each manuscript specifies the graph class, the inputs supplied with an instance and the permitted uses of each control. Historical attribution is given in each manuscript.

The matching and query paper proves bounds for exact deterministic truth-table queries in a specified Gap-MCSP regime. Its results concern that query model. The Beaver Math Olympiad notes give obstructions to several modular-invariant approaches and establish a lower bound of 21,999,878 individual rewrites for a jam in problem 11. These are partial results on the prescribed-start problems.

The archive is organized by manuscript and includes the original checks and finite examples. The Beaver notes carry their source code as attachments. This collection is submitted as working manuscripts with AI assistance for independent review.
