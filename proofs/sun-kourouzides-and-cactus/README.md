# Prime-counting inequalities, equilateral-triangle rays and a cactus-graph case

The manuscript proves Sun’s prime-counting inequalities 2.7(i) and 2.14(ii), derives the ray-count formula for [OEIS A387471](https://oeis.org/A387471), and proves a restricted case of Written on the Wall II 133 for cactus graphs. It includes finite results for Sun’s coefficient 1680 ([A280831](https://oeis.org/A280831)). The broader four-square question remains open in this manuscript.

The PDF contains the first four pages on the infinite results. The editable TeX source also includes the finite four-square section.

The file `check.py` reproduces the prime-counting boundary checks, the root-of-unity enumeration, direct triangle checks and the four-square computation using Python’s standard library. The infinite arguments are given in the paper. The manuscript includes source credits, and Sun 2.14(ii) also has an [earlier project record](https://github.com/DomTheDeveloper/formal-conjectures/pull/102). Prepared with AI assistance.
